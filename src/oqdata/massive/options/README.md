# oqdata.massive.options

Massive market-data client, quote/trade processing, option contracts and ticker histories.

```python
from oqdata.massive import MassiveClient
client = MassiveClient()
```

MASSIVE_TOKEN. Data paths come from `oqdata.env`: `OQ_DATA_ROOT`, `OQ_DATA_RAW`, and `OQ_DATA_PROCESSED`.

Set `OQ_DATA_TEST_MODE=1` and `OQ_DATA_TEST_ROOT` to an existing fixture root to read local caches without provider access.

- `__init__.py`: Massive.com Options Data Module. Public entry points: package exports.
- `contracts.py`: oqdata.massive.options.contracts. Public entry points: `REJECTED`, `ContractsFilter`, `filter_contracts`, `filter_contracts_between`, `main`.

Processing modules provide `python -m oqdata.<source>.<module> --help`. New adapters accept a function name and `--params` containing JSON keyword arguments. Existing specialized commands retain their own options.

See [Download an option chain, quotes and trades](notebooks/download_options_quotes_trades.ipynb) for a complete ticker/date example with DTE, moneyness and volume filters, downloads for every selected contract, and per-option progress and errors.

**Existing contract data:** Do not use `spot_prev_close` from caches generated by
`filter_contracts` version 0.24 or earlier. They contain the adjusted previous
close where the unadjusted close was intended. Version 0.25 fixes the request
and invalidates older caches; the separately computed `spot_ref_prev_close`
and the NMS/NMS5 filters are unaffected by this error.
