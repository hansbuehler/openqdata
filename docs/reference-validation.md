## Pipeline and case sizes

Each case rebuilds the initial WIDB filters and enrichment from frozen raw observations. `mk_arb_free_day` runs the per-expiry reference fit and the full linear DLV surface fit. The usual OptionsFilter then selects the model's option universe, followed by `mk_arb_free_day` with smoothness 0.25 on that universe. The option-selection thresholds match the original research workflow's defaults. Selection uses `normalize=False` to retain the WIDB enriched-table schema; pure forward-price/strike inputs and selected contract identities are unchanged by cash-unit normalization.

The smooth fit therefore follows the original research workflow's option-filter-before-smoothing ordering, using `mk_arb_free_day` for both fitting stages.

## Older stored files are a different baseline

The existing stored reference files were introduced in commit `e5bc1e1` on 2026-05-11. Their metadata records MkArbFree 0.2; the current implementation is 0.81. Historical defaults used per-expiry Clarabel and NMS, while current defaults use HiGHS and NMS5 and add nms_atm. Consequently the old per-expiry fitted tables do not match current regenerated results; this drift also occurs when running the original quant_data code and is not introduced by quantdata.

Ten raw cases exactly reproduce the older raw snapshots. SPX 2024-12-26 and 2025-01-03 now remove the irregular 2025-01-09 expiry: respectively 151 and 158 raw rows, leaving 11,284 and 11,100 rows. Enrichment retains 9,146 and 8,493 rows instead of the older 9,279 and 8,629. Stored reference files were not overwritten.

The old references contain no smooth SANOS baseline. For DLV and smooth SANOS, the current quant_data source is the separately executed control implementation.
